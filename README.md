# RFM Customer Analysis Dashboard
# Live Dashboard
Open RFM Customer Analysis Dashboard: (https://rfm-customer-analysis-sayan.streamlit.app/)

# Dashboard Preview

An interactive customer segmentation dashboard built with Python and Streamlit using RFM (Recency, Frequency, Monetary) analysis.

# Project Overview

This project analyses customer purchasing behaviour to identify valuable customers, understand purchasing patterns, and generate actionable business insights.

# Features

- Interactive customer and sales KPI dashboard
- Recency, Frequency and Monetary analysis
- RFM scoring and customer segmentation
- Customer-level details and filtering
- Business insights for customer retention
- Downloadable customer analysis data

# Technologies Used

- Python
- Pandas
- Streamlit
- NumPy
- Plotly 

# Project Structure

- 'app.py' - interactive dashboard
- 'rfm_analysis.py' - RFM analysis logic
- 'requirements.txt' - project dependencies
- 'data/sales_data.csv' - dataset used for analysis

# Run Locally
Install the required packages:

'pip install -r requirements.txt'

Start the dashboard:

'streamlit run app.py'

# Purpose

This project demonstrates practical skills in data analysis, customer segmentation, data visualization, and business decision support.

# Disclaimer

This project is intended for educational and portfolio purposes. Results depend on the dataset and the assumptions used for RFM scoring.
